# Настройка бронирования без отдельного бота-хоста

Реакции Discord нельзя поймать сайтом без постоянно работающего gateway-бота.
Поэтому здесь реакции заменены на кнопки Discord:

- ✅ Забронировать проведение
- ❌ Отменить бронь

Кнопки Discord отправляют HTTP interaction прямо на сайт/Vercel.

## Что нужно в Vercel / env сайта

Добавь переменные:

```env
DISCORD_BOT_TOKEN=токен_твоего_discord_бота
DISCORD_PUBLIC_KEY=public_key_из_Discord_Developer_Portal
```

После этого сделай Redeploy.

## Что нужно в Discord Developer Portal

1. Открой приложение бота.
2. Перейди в **General Information**.
3. Скопируй **Public Key** и вставь его в Vercel как `DISCORD_PUBLIC_KEY`.
4. В поле **Interactions Endpoint URL** укажи:

```text
https://АДРЕС-ТВОЕГО-САЙТА/api/discord-interactions
```

5. Нажми Save.

Discord проверит endpoint:
- отправит PING;
- проверит подпись запроса.

Если всё правильно, URL сохранится.

## Как это работает

1. Сайт отправляет embed про флот/дипломатию в канал логов карты.
2. Под embed будут кнопки.
3. Ивентолог с ролью `1305567485218521169` нажимает кнопку.
4. Discord отправляет interaction на сайт.
5. Сайт отправляет новое сообщение в канал бронирований `1512560293740548146`.
6. Под новым сообщением бронирования сайт создаёт ветку.
